# SimpleNote — Java

Reimplementação em **Java** de um projeto de anotações que desenvolvi originalmente em C# durante meus estudos.

O objetivo deste projeto é reconstruir a aplicação utilizando **Java e JavaFX**, aprofundando meus conhecimentos na linguagem e aprendendo desenvolvimento de interfaces gráficas no ecossistema Java.

Nesta primeira versão, as anotações serão armazenadas localmente. Futuramente, pretendo implementar integração com banco de dados.

## Tecnologias

* Java
* JavaFX
* FXML

## Planejado para a primeira versão

* [ ] Criar anotações
* [ ] Editar anotações
* [ ] Excluir anotações
* [ ] Listar anotações
* [ ] Salvar as anotações localmente
* [ ] Carregar notas salvas
* [ ] Desenvolver e estilizar a interface com JavaFX

## Futuras melhorias

* Integração com banco de dados
* Sistema de usuários
* Busca de anotações
* Favoritos e organização das notas
